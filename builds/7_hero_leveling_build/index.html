Introduction

This build is ideal for new camplaign playthroughs where the player already unlocked a lot of skills for heroes. The idea is to swap out heroes as needed as you unlock heroes throught the campaign playthrough.

In the end the build should look something like this:

  • 3 x Domination Mesmers
  • 2 x Healers
  • 1 x BiP Necro
  • 1 x SoS Spirit Spammer
